# 智慧农场课堂网页素材

网页场景使用 Kenney 的 [Pixel Platformer Farm Expansion](https://kenney.nl/assets/pixel-platformer-farm-expansion) 和 [Pixel Platformer Industrial Expansion](https://kenney.nl/assets/pixel-platformer-industrial-expansion) 两套游戏图块。两套素材均由 Kenney 发布，采用 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 许可。图块表已内嵌到 `智慧农场_突发事件系统设计课堂.html`，课堂使用只需复制 HTML 文件。

农田、作物、温室和部分设备由独立图块实时拼搭，随事件改变。天气、供水、虫情、控制和失败效果由本项目的 JavaScript 在 Canvas 中逐帧绘制。网页未连接真实农业设备。
